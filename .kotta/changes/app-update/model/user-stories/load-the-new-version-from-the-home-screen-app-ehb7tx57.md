# Load the new version from the home-screen app

## Story

As a phone user who keeps the app on the home screen, I want the app to tell me when a new version is out and to load it with one tap, and to load the day again when I ask, so that I get the latest app and see what I logged through Claude without removing the app from the home screen.

## Value

The home-screen app has no address bar and no reload, so today a fix reaches the phone only by chance. Entries logged in Claude show up on the plate only after the day is loaded again.

## Notes

The app is installable with its own name ("Health AI") and icon and opens without the browser bar. The web app in a browser tab gets the same bar and button.
