# Correct a logged meal

## Story

As a phone user, I want to change a meal I already logged (portion, item, meal type), so that my balance stays right.

## Value

Corrections are common (a lunch that was logged as a snack, half a portion). Google Health cannot edit a saved meal, so the app saves the corrected one and removes the old, and the entry gets a new id.
