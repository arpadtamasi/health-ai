# Reach my own health data from any AI chat

## Outcome

The owner and invited testers use their own Google Health data from an MCP-capable AI chat through one remote server, without installing anything locally.

## Context

The Fitbit Web API shuts down on 2026-09-30; the server is built on the Google Health API v4. Users: the owner and invited testers (at most 100, Google OAuth Testing mode).

## Baseline and target

Baseline: no such tool exists for the owner today.

Target: I use Health AI in at least 3 conversations a week that use my own data, for 4 consecutive weeks.
