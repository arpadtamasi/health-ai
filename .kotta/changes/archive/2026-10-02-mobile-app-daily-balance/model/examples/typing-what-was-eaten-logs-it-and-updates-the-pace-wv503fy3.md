# Typing what was eaten logs it and updates the pace

## Given

It is 14:20 and the user is 209 kcal under pace.

## When

The user writes "Had a slice of pogácsa and a tea" in the chat.

## Then

The chat replies that it logged a pogácsa (110 kcal) and an unsweetened tea as a snack, and says the user is now 99 kcal under pace; the Today screen shows the same.
