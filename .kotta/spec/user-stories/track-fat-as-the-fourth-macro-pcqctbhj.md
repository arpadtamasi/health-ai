# Track fat as the fourth macro

## Story

As a phone user, I want a fat goal next to calories, protein and carbs, set in the first conversation and changeable by chat, so that I can keep to a macro plan such as the low-carb one my doctor suggested.

## Value

In the owner's logs the fat became the tight number of the day and the goals were read from a screenshot of Google Health's macro goals; the app tracked only calories, carbs and protein.

## Notes

The first conversation estimates all four from the person's data and the person accepts or changes them. The estimate for the owner's case (100 kg to 90 kg) was 2,100 kcal, protein 160 g, carbs 185 g, fat 80 g.
