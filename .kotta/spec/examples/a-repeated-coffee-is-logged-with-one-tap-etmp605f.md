# A repeated coffee is logged with one tap

## Given

The user has logged a cappuccino nine times in the last 30 days.

## When

The user opens Quick add and taps Log next to Cappuccino.

## Then

The cappuccino is logged at the current time and an "Undo" message is shown for a moment.
