# The chat changes the goal and the quick-add buttons

## Given

The daily goal is 1,900 kcal, the quick-add buttons are Cappuccino, Oat bran and Apple, and the chat is open.

## When

The user writes "Add tea to my buttons, drop the apple, and make the goal 1,800".

## Then

The chat replies with what it changed (Tea added, Apple removed, goal 1,900 → 1,800 kcal) and offers Undo; the Quick add screen shows Cappuccino, Oat bran and Tea, and the Today screen counts against 1,800.
